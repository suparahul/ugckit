# Slideshow Anatomy — the parameters of a TikTok photo-mode post

An anatomy is a list of parameters. Each parameter has a fixed set of values that we have seen work. An experiment changes one parameter and holds the rest. Outcomes are compared across rows of the post table at the end of this file.

Every value below comes from evidence in `learnings-slideshows.md` (cited by section), the slide-by-slide reads in `SCROLLED-SLIDESHOW-BATCH-2026-09-12.md` (cited by post number), or the corpus documents `PLAYBOOK.md` and `FUNDAMENTALS-REVIEW.md` (cited by section or item). No value is invented. Where the evidence is thin, the table says so.

Each layer holds parameters. Each parameter is a heading. Under the heading, one table: one row per value we have seen.

**Seen in** lists the niches the value was seen in. A value seen in two or more niches is treated as niche-agnostic. A value seen in one niche only is not yet known to transfer. **(claimed)** in the evidence means a creator described the value in a post or thread; we did not see a post that uses it.

**Rules to avoid overlap.** Deck shape never names the product; the product slot does. Image style says what the viewer sees; image subject says who or what is in the frame; image origin says where the picture came from. Persona is a property of the account, not of the post, so it sits in its own layer.

## Niche-agnostic and niche-specific

The parameters and the layers are the same for any niche. Only some values change with the niche.

**Niche-specific values.** The named reader wording. The keepable content type. The keyword choice. The persona. The image subject (a cat account uses its own cat; a dating account uses a stock couple).

**Niche-agnostic values, as far as the evidence goes.** Deck shape. Slide-count bands. Hook shapes. Product slot. Text density. Image style. Each of these has been seen in at least two niches (cat, gym, dating, health, mental health, couples, cooking).

**Seen in one niche only.** The haul, the follow ask, the save-plus-reason ask, the send-to-someone ask, the comment-a-question ask and the paragraph density are cat-only. The store end card and the accusation hook are gym-only. They stay unproven elsewhere until another niche shows them.

## How to run an experiment

1. Pick one parameter from one layer.
2. Hold every other parameter at its best-seen value from the tables above. For a cat tip slideshow, post 8 is the best-seen row for saves. Post 3 is the best-seen row for views with saves.
3. Make the post. Record every parameter value before you post.
4. Post it. After seven days, add one row to the post table with the outcome columns filled.
5. Compare the new row with the rows that differ only in that parameter. A change in the outcome column that the parameter targets is the result. The last-slide ask moves the metric it names (§ scrolled batch, "Last slide"), so pick the outcome column before you pick the value.
6. Repeat with the next parameter. Never change two parameters in one post.
