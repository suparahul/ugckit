# UGC Ultra System

Merged skill built from the supplied `ugc-ad-system` and `one-face-lock` packages.

It combines:
- winning-ad reverse engineering;
- ad-mechanism selection;
- hyper-real creator reference prompting;
- hard creator / voice / lighting / wardrobe locks;
- product + UI locks;
- one-face 50-script packs;
- generation-ready video prompting;
- Seedance 2.5 advanced prompting reference;
- controlled multi-creator/product/angle scaling;
- drift + pre-generation quality control.

## Modes

- **Hero Ad Rebuild** — competitor/reference ad → rebuilt production prompt.
- **One-Face 50 Pack** — one creator, 50 consistent UGC cards. This is the default batch mode.
- **Controlled Matrix Scale** — multiple creators/products/angles only when explicitly requested.

## Install

Use the whole `ugc-ultra-system` folder as one skill. Keep `SKILL.md`, `references/`, `examples/`, and `agents/` together.

The included Seedance file is retained as a detailed model-specific reference; the top-level `SKILL.md` is the orchestrator and resolves conflicts between the two original systems.
